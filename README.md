# FORM / CT — GitHub Pages edition

Browser-based CT-style mesh readings and editable vector graphics.

## Publish

Upload the contents of this folder to the root of your GitHub repository, preserving the sample and vendor folders. In Settings > Pages, choose Deploy from a branch, select your default branch and /(root), then Save. The repository Settings > Pages screen will show the website URL when deployment finishes.

No installation or build step is required. The .nojekyll file keeps the bundled files served directly. All app asset paths are relative so the site works at a repository URL.

Uploaded models are processed in your browser. The bundled Caltrans example is part of the website download. These graphics simulate CT appearance from mesh geometry and texture; they are not measured internal CT data.

Source and exports remain editable. See the local studio README for full controls and export details.
